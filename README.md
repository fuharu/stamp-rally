# スタンプラリー地図アプリ (Vite + React)

## セットアップ手順

1. `.env` ファイルの `VITE_GOOGLE_MAPS_API_KEY` にGoogle Maps APIキーを設定
2. 依存パッケージをインストール
   ```sh
   npm install
   ```
3. 開発サーバー起動
   ```sh
   npm run dev
   ```

---

## 最小構成で実装される機能
- Googleマップ表示
- 複数のスタンプポイント（マーカー）設置
- マーカークリックで「スタンプGET」状態
- 取得済みスタンプのリスト表示

---
