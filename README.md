# スタンプラリー地図アプリ (Vite + React)

地域の観光地を巡ってスタンプを集めるスタンプラリーアプリです。

## 🚀 新機能: AIスタンプ生成

### 🎨 Stable Diffusionによるカスタムスタンプ生成

地域名を入力するだけで、AIがその地域の景色や特産物をモチーフにしたスタンプ画像を自動生成します。

#### 機能
- **地域名入力**: 任意の地域名（例：東京、京都、大阪、札幌など）を入力
- **AI画像生成**: Stable Diffusionを使用してスタンプデザインを自動生成
- **スタイル**: 日本の伝統的なスタンプデザイン、浮世絵風、モダンなデザインなど
- **キャッシュ機能**: 生成された画像は24時間キャッシュされ、再生成を回避
- **履歴管理**: 生成したスタンプの履歴を保存・管理
- **カスタムスタンプ**: 生成したスタンプを通常のスタンプとして使用可能

#### 対応API
1. **Stability AI** (推奨)
   - 高品質な画像生成
   - 安定したAPI
   - [Stability AI](https://platform.stability.ai/)でAPIキーを取得

2. **Replicate** (代替)
   - オープンソースモデルを使用
   - [Replicate](https://replicate.com/)でAPIキーを取得

#### セットアップ

1. **APIキーの取得**
   ```bash
   # Stability AIの場合
   # https://platform.stability.ai/ でアカウント作成・APIキー取得
   
   # Replicateの場合
   # https://replicate.com/ でアカウント作成・APIキー取得
   ```

2. **環境変数の設定**
   ```bash
   # .envファイルを作成
   cp env.example .env
   
   # APIキーを設定（どちらか一方）
   VITE_STABILITY_API_KEY=your_stability_api_key_here
   # または
   VITE_REPLICATE_API_KEY=your_replicate_api_key_here
   ```

3. **アプリケーションの起動**
   ```bash
   npm run dev
   ```

#### 使用方法

1. スタンプラリーページで「🎨 AIスタンプ生成」ボタンをクリック
2. 地域名を入力（例：「東京」「京都」「大阪」など）
3. 「生成」ボタンをクリック
4. AIがスタンプ画像を生成（通常30秒程度）
5. 生成されたスタンプを「使用」ボタンでコレクションに追加

#### 生成されるスタンプの特徴

- **デザイン**: 円形のスタンプ形式
- **スタイル**: 日本の伝統的なアートスタイル
- **モチーフ**: 地域の名所、特産物、文化的要素
- **品質**: 高解像度（1024x1024）
- **バリエーション**: 複数のプロンプトパターンで多様なデザイン

#### 注意事項

- APIキーの設定が必要です
- 画像生成には時間がかかる場合があります
- 生成された画像は24時間キャッシュされます
- API使用量に応じて料金が発生する場合があります

## 技術スタック

- **フロントエンド**: React, Vite
- **地図**: Google Maps API
- **AI画像生成**: Stable Diffusion (Stability AI / Replicate)
- **バックエンド**: Node.js, Express
- **データベース**: PostgreSQL
- **認証**: Firebase Authentication

## セットアップ手順

1. `.env` ファイルの `VITE_GOOGLE_MAPS_API_KEY` にGoogle Maps APIキーを設定
2. 依存パッケージをインストール
   ```sh
   npm install
   ```
3. 開発サーバー起動
   ```sh
   npm run dev
   ```
